# Project Overview
This was a project for my COMP 484 course about web development.

The project was to create a website with HTML and CSS using three unique HTML elements and three unique HTML attributes.

## Elements
For this project, I used &lt;template&gt;, &lt;datalist&gt;, and &lt;output&gt; as my unique elements.

* &lt;template&gt; 
  * Was used to hide content until a button was clicked, with JavaScript used to reveal the content.
* &lt;datalist&gt;
  * Was used to provide a list of boss names as suggestions for the search input.
* &lt;output&gt;
  * Was used to display the result of the short quiz.

## Attributes
For the attributes, I used &lt;autocomplete&gt;, &lt;enterkeyhint&gt;, and &lt;inputmode&gt;.

* &lt;autocomplete&gt;
  * Was used to allow the browser to suggest previously entered values in the search input.
* &lt;enterkeyhint&gt;
  * Was used to indicate that the Enter key should display a ‘Go’ action on supported keyboards.
* &lt;inputmode&gt;
  * Was used to tell mobile devices to display a search-optimized keyboard when the input is selected.

## What I learned
* I learned how to use HTML and CSS for my own website.
* I learned some elements and attributes on my own outside of what was taught in class.
* I learned how to use JavaScript to interact with the project.
